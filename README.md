# Cloud Database Maintenance Fee Collection with Secure Complaint Handling

## Project Overview
A secure cloud-deployed web application designed to manage maintenance fee collection, document security, and complaint handling through role-based access control.

## Key Features
- Role-Based Access Control (RBAC)
- Secure User Authentication
- Hybrid RSA–AES Encryption
- Secure File Upload and Download
- Maintenance Fee Management
- Complaint Management System
- Audit Logging
- Multiple User Roles

## Technologies Used
- Python
- Flask
- HTML, CSS, JavaScript
- TinyDB
- RSA and AES-GCM
- AWS EC2
- Ubuntu Linux
- SSH

## Cloud Deployment
The application was deployed on Amazon AWS EC2 using Ubuntu Linux.

Deployment activities included:
- EC2 instance configuration
- Ubuntu server management
- Remote access using SSH
- AWS Security Group configuration

## Project Structure
- `routes/` – Application routes and functionality
- `templates/` – HTML pages
- `static/` – CSS, JavaScript and static assets
- `app.py` – Flask application configuration
- `database.py` – Database operations
- `encryption.py` – Encryption and decryption functionality
- `main.py` – Application entry point

- Understanding cloud deployment using AWS EC2
- Working with Linux servers
- Implementing authentication and access control
- Understanding hybrid encryption
- Managing application data using TinyDB
